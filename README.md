## 🧰 Troubleshooting

### WinSCP Cannot Connect to the Server

- 🌐 Check your internet or network connection.
- 🖥️ Verify the hostname and port with your hosting provider or server administrator.
- 🔒 Confirm that the selected protocol matches the server configuration.
- 🛡️ Check firewall rules and network restrictions.
- 🔄 Try connecting again after verifying the session settings.

### Authentication Failed

- 🔑 Verify your username and authentication method.
- 🔐 Check your password or SSH private-key configuration.
- 🧩 Confirm that your account has permission to access the server.
- 📚 Contact the server administrator if your account is locked or access has been restricted.

### File Upload or Download Fails

- 📂 Check that the destination directory exists.
- 🔐 Verify your permissions for reading, writing, or creating files.
- 💾 Make sure there is enough available storage.
- 🌐 Check for interrupted network connections and retry the transfer if appropriate.

### Host Key or Certificate Warning Appears

- 🔒 Verify the host key or certificate fingerprint through a trusted channel.
- 🛑 Do not blindly accept unexpected security changes.
- 🧑‍💻 Contact the server administrator if the fingerprint differs from the expected value.

### Transfers Are Slow

- 🌐 Check the connection quality and server performance.
- 📊 Review transfer settings and any bandwidth restrictions.
- 📁 Consider whether many small files are increasing transfer overhead.
- 🛡️ Check whether a VPN, proxy, or firewall is affecting the connection.
